# M0 검증 앱 (WP-01)

창을 띄워 봐야 알 수 있는 것(SPEC §9, ARCHITECTURE §6)을 사용자가 직접 눌러 보고 판정하는 실험 앱이다.
버리는 코드이며 루트 작업 공간에 속하지 않는다(`Cargo.toml` 의 빈 `[workspace]`).

## 실행

```sh
cd spikes/m0
export CARGO_TARGET_DIR=<저장소>/target   # 의존성 빌드 결과 공유
cargo run -- <저장소>/references/viewers/tdf/benches/geotopo.pdf
```

선택 인자

| 인자 | 뜻 |
|---|---|
| `파일.pdf …` | 여러 개 가능. 파일마다 주 창에 탭 2개(1쪽, 2쪽), 창 1 에 탭 1개(1쪽)를 연다 |
| `--font=system` | 기본값. eframe 0.37 의 시스템 글꼴 대체(fontique)에 맡긴다 |
| `--font=noto` | 시스템 대체를 끄고 Noto Sans CJK KR 을 font-kit 으로 찾아 직접 불러온다 |
| `--font=none` | 시스템 대체를 끄고 아무것도 더하지 않는다. 대조군(한글이 네모로 나와야 정상) |
| `--smoke-test` | 창을 띄우고 2초 뒤 스스로 종료. 문서가 열리고 텍스처가 하나 이상 생기면 종료 코드 0 |

화면 구성(창마다 같음)

- 위: 창 번호, "새 창", "PDF 열기…", 결합 판정 시간 슬라이더(50~500ms, 기본 150), 현재 글꼴 모드, 한글 입력 칸.
- 가운데: `egui_dock` 도킹 영역. 탭 안에 이전/다음 쪽 버튼, 텍스처 id, 이미지 복사 버튼 (a)(b), 쪽 그림.
- 아래: 기록 영역. 같은 내용이 표준 출력에도 찍힌다. 결과를 적을 때 여기 내용을 복사한다.

탭 제목은 `파일명 · N쪽 (탭 #키)` 이다. 창 번호는 주 창이 0, 그 뒤로 1, 2, … (닫힌 번호는 다시 쓰지 않음).

### 4. 탭을 다른 창 위에 끌어 놓으면 그 창에 붙는가. 10번 중 몇 번 되는가

- 할 일: 창 0 과 창 1 을 겹치지 않게 나란히 둔다. 창 0 의 탭을 끌어 창 1 의 가운데에 놓는다. 10번 반복한다
  (반대 방향도 몇 번). 놓은 뒤 마우스를 움직이지 않는 경우와 살짝 움직이는 경우를 나눠 본다.
  판정 시간을 바꿔(예: 50, 150, 300ms) 결과가 달라지는지도 본다.
- 보여야 할 것: 탭이 창 1 에 붙는다. 기록에 `놓은 뒤 NNms 에 창 1 이 포인터를 받음` 과
  `판정 끝 … 창 1 에 결합`. 실패하면 `새 창으로 분리 (… 다른 창이 포인터를 받지 못함)`.

## 판정 방식 (4번) 의 구현

- 탭 버튼 위에서 누른 채 끌기 시작하면(`is_decidedly_dragging`) 그 창이 끌기를 추적한다.
  끄는 동안 창 밖 좌표가 들어오면 기록한다(Wayland 의 암묵적 포인터 잡기로 들어오는지 확인).
- 그 창에서 `primary_released` 가 왔을 때 포인터가 창 영역 밖이면 "창 밖에 놓음"으로 보고 시각을 기록한다.
- 그 뒤 모든 창의 프레임마다 `has_pointer` 를 기록한다(500ms 동안). 판정 시간 안에 출발 창이 아닌 창이
  포인터를 가지면 그 창에 결합, 시간이 지나도록 없으면 새 창으로 분리한다.
- 자식 창은 immediate 뷰포트라 주 창 프레임 안에서 함께 그려진다. 판정 중에는 계속 다시 그리게 한다.
